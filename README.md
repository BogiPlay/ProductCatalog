# Каталог на продукти – WPF + SQLite + CRUD

Практически проект по **Урок 13** (филтриране и обновяване) и **Урок 14** (SQLite CRUD).

## Как се стартира

1. Разархивирайте папката и отворете **`ProductCatalog.sln`** с Visual Studio 2026.
2. Натиснете **F5**. При първия Build NuGet пакетът `Microsoft.Data.Sqlite` се изтегля автоматично (нужен е интернет).
3. При първо стартиране се създава база с 12 примерни продукта.

Изисквания: Windows 10/11, .NET 10 SDK (идва с Visual Studio 2026, работно натоварване „.NET desktop development“).

Базата данни се намира в `%LocalAppData%\ProductCatalog\products.db`.
Пътят се вижда в долната лента; кликнете върху него, за да отворите папката.

## Архитектура (Урок 14)

| Слой | Файл | Роля |
|---|---|---|
| UI | `MainWindow.xaml` | XAML контроли: `txtSearch`, `btnSearch`, `gridProducts`, `txtName`, `numPrice` … |
| Логика | `MainWindow.xaml.cs` | `LoadProducts(term)`, `AddProduct()`, `UpdateProduct()`, `DeleteProduct()` |
| Данни | `Services/DatabaseService.cs` | `SqliteConnection` + **параметризирани** команди |
| Модел | `Models/Product.cs` | `Product` с `Id`, `Name`, `Price` (+ разширения) |
| Валидация | `Services/ProductValidator.cs` | празно име, невалидна цена, наличност |
| Контрола | `Controls/NumericBox.xaml` | цифрово поле (в WPF няма вграден NumericUpDown) |

**Поток:** бутон → обработчик (`BtnUpdate_Click`) → метод (`UpdateProduct`) →
SQL (`UPDATE Products SET Name = $name, Price = $price WHERE Id = $id`) → `LoadProducts()` → DataGrid.

## Изисквания от уроците ✔

- Търсене с `SELECT … WHERE Name LIKE $term` (параметър, без слепване на SQL текст)
- Празно търсене → всички записи; няма резултати → съобщение
- Избор на ред → данните отиват в полетата → `UPDATE … WHERE Id = $id` → презареждане
- Добавяне, зареждане, редакция, изтриване (CRUD)
- Валидация: празно име, невалидна цена, липсващ избор при редакция/изтриване
- Ясно съобщение за успех или грешка, без срив
- Данните остават след затваряне (SQLite файл)

## Допълнителни възможности

- Модерен интерфейс със собствена заглавна лента, **тъмна и светла тема** (помни се в SQLite)
- Статистика: брой продукти, стойност на склада, средна цена, ниска наличност
- Търсене „на живо“ (и по категория/описание, `#номер` за търсене по Id), работи и на кирилица
- Филтри: категория, ценови диапазон, само ниска наличност; подредба (ORDER BY)
- Нови полета: категория, наличност, описание, дати на създаване/промяна
- Цветни индикатори за наличност (в наличност / ниска / изчерпан)
- Потвърждение преди изтриване + **„Отмени изтриването“**
- Предупреждение при дублирано име, проверка „няма промени“
- Дублиране на продукт, контекстно меню (десен бутон), двоен клик
- Експорт в CSV (отваря се в Excel с кирилица)
- Известия (toast) и лента за състояние с последната операция
- Клавиши: `Ctrl+N` нов · `Ctrl+S` запис · `Del` изтриване · `Ctrl+F` търсене · `Ctrl+D` дублиране · `Ctrl+E` експорт · `F5` обнови · `Esc`

## Контролен списък за тестване (Урок 14)

1. Добавяне на „Клавиатура“, цена 49.90 → появява се в таблицата.
2. Добавяне с празно име → червено съобщение под полето, **без INSERT**.
3. Изтриване без избран ред → съобщение „Няма избран продукт“.
4. Редакция на съществуващ запис → променя се само избраният Id.
5. Затваряне и ново стартиране → данните са запазени.
